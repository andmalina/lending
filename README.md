# RUTUBE КРУГ

Красочный адаптивный лендинг сообщества авторов RUTUBE — с видео, комментариями, лайками и формой вступления в круг.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Публикация (GitHub Pages)

Сайт разворачивается из ветки `main`, папка `/docs`.

```bash
npm run build          # собирает в docs/
git add docs
git commit -m "Deploy"
git push
```

Доступен по адресу: https://andmalina.github.io/lending/
